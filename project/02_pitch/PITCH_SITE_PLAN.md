# IshMed — Pitch Site

**Статус:** первый статический релиз готов.  
**Роль:** pitch deck в формате сайта и коммерческая витрина.  
**Продукт P0:** Telegram-бот.

## Готовые страницы

- `../../pitch-site/index.html` — общая история продукта.
- `../../pitch-site/clinics.html` — ценность для клиник.
- `../../pitch-site/pilot.html` — 30-дневный пилот.
- `../../pitch-site/medics.html` — ценность и приватность для медиков.
- `../../pitch-site/pages.css` — общая система внутренних страниц.

Страницы статичны, адаптивны и не отправляют данные. Текущие формы — демонстрационные.

## Следующий P0-шаг сайта

После появления Telegram username/URL заменить главные CTA:

- `Создать профиль` → deep link бота с ролью медика;
- `Найти специалиста` → deep link бота с ролью клиники;
- `Стать пилотом` → согласованный контакт или короткая рабочая форма.

Не строить отдельный web onboarding до готовности Telegram P0.

## История для pitch

1. Медицинский найм разбит между Telegram, job boards, звонками и таблицами.
2. Медсестра описывает себя одним голосовым сообщением.
3. IshMed создаёт редактируемый конфиденциальный профиль.
4. Клиника описывает потребность и получает объяснимый match.
5. Контакт открывается после invite + accept.
6. Начинаем с медсестёр и частных клиник Ташкента.
7. Следующий шаг — три 30-дневных пилота.
