# IshMed — Visual Direction

**Статус:** зафиксировано по текущему pitch-site и бренд-референсу EzguPro.

## Характер

- доверительный и современный;
- медицинский без больничной стерильности;
- технологичный без роботов и «магического AI»;
- ясный, быстрый, человеческий.

## Название

- Бренд: `IshMed`.
- Текущий текстовый wordmark: `ISHMED`, акцент на `MED` градиентом.
- Домен: `ishmed.uz`.
- Слоган: «Работа для медиков. Медики для клиник.»
- Узбекская опорная фраза: «Mos ish. Mos mutaxassis.»

Новый графический знак не придумывать без отдельного решения.

## Палитра

- Ink: `#08162F`;
- Text: `#303B52`;
- Muted: `#697388`;
- Line: `#E4E9F1`;
- Soft: `#F6F8FC`;
- White: `#FFFFFF`;
- Violet: `#673CFF`;
- Blue: `#1673FF`;
- Cyan: `#14BCD0`;
- Green: `#49D45E`.

Главный градиент: violet → blue → cyan → green. Это продолжение визуальной ДНК EzguPro, не новый логотип.

## Product visuals

- крупный главный экран, минимум мелких деталей;
- Telegram voice card → структурированные поля → match;
- приватность показывать через скрытый контакт и явное согласие;
- реальные контакты и персональные данные не использовать;
- synthetic/demo данные помечать в служебном контексте.

## Изображения и motion

- современные медицинские специалисты Центральной Азии;
- естественная рабочая среда;
- без стоковых рукопожатий и цифровых роботов;
- анимация может показать голос → профиль → match, но не должна быть нужна для понимания.
