Вот примерный бизнес-план и структура коммерческого предложения для проекта ezguMed («Тиндер для медиков»), адаптированного под реалии рынка Узбекистана.

Концепция проекта: ezguMed — ИИ-ассистент медицинского рекрутинга
Проблема: В настоящий момент медицинский рекрутинг в Узбекистане глубоко фрагментирован. Клиники ищут персонал через универсальные доски (OLX.uz, HH.uz) или разрозненные Telegram-каналы (MedRabota, clinics.uz), где вакансии перемешаны, а пре-фильтрация кандидатов отсутствует. Врачи и медсестры, работающие сменами, не имеют времени составлять классические резюме.
Решение: Вертикально-интегрированная SaaS-платформа с ИИ-мэтчингом, объединяющая удобство Telegram-бота для соискателей и мощный веб-кабинет для клиник и вузов.  

Ценностное предложение (Value Proposition) по ролям
1. Для Клиник (B2B сегмент)
Боль: Высокая стоимость найма, долгий поиск узких специалистов, отклики неквалифицированных кандидатов (шум).

Решение: Прямой доступ к отфильтрованной базе пассивных и активных соискателей. Алгоритм сопоставляет требования вакансии (например, врач УЗИ в Фергане с ожиданием ЗП 10-15 млн сумов) с профилями соискателей.  

Выгода: Клиника платит только за «свайп вправо» (совпадение) или по модели подписки за доступ к базе. Интеграция с уже используемыми HR-платформами, такими как локальный Jobster, для автоматической рассылки и ведения базы.  

2. Для Врачей и Медсестер (B2C сегмент)
Боль: Сложность составления резюме, поиск работы в десятках Telegram-каналов, страх деанонимизации перед текущим работодателем.

Решение: Общение с ИИ-ботом в Telegram с помощью голоса. Бот задает вопросы, распознает голосовые ответы, структурирует опыт, специализацию и пожелания по зарплате (например, медсестра в стоматологию на 3-4 млн сумов), создавая микро-резюме за 2 минуты.  

Выгода: 100% бесплатно. Полная анонимность до момента, пока кандидат сам не согласится открыть контакты конкретной клинике (механика двойного согласия).

3. Для Медицинских Университетов (B2G/B2B сегмент)
Боль: Сложность трудоустройства выпускников, отсутствие прозрачной статистики по карьерным трекам (кто, куда и на какую зарплату устроился).

Решение: Институциональные аккаунты. Университет централизованно загружает профили выпускников-ординаторов.

Выгода: Кабинет аналитики (Dashboard), показывающий процент трудоустроенных, среднюю стартовую зарплату выпускников и отзывы клиник о качестве подготовки. Повышает престиж вуза и закрывает требования регуляторов по мониторингу трудоустройства.

Архитектура продукта и Пользовательский путь (User Journey)
Шаг 1: Онбординг (Вход)

Врач заходит в Telegram-бот и надиктовывает: «Я педиатр, стаж 3 года, ищу работу в Алмазарском районе от 6 миллионов сум». Бот с помощью NLP (обработки естественного языка) переводит это в теги.  

Клиника в веб-кабинете создает карточку вакансии за пару кликов.

Шаг 2: Алгоритм Мэтчинга (Тот самый "Тиндер")

ИИ анализирует базу. Клиника видит в кабинете анонимные карточки подходящих кандидатов (опыт, навыки, локация) без имен. Врач получает в Telegram карточки клиник, ищущих его профиль.  

Шаг 3: Совпадение (Match)

Если клиника нажимает «Пригласить», а врач в Telegram нажимает «Интересно», происходит Match. Только после этого клинике открывается ФИО и номер телефона врача.

Бизнес-модель и Монетизация
Вместо устаревшей продажи «публикации вакансий», проект использует гибридную микротранзакционную модель и SaaS (аналогично успешным мировым практикам вроде Healthtal и Imperium App):  

Для соискателей: Абсолютно бесплатно (Freemium).

Pay-per-Match (Микротранзакции): Клиника публикует вакансии бесплатно. Плата взимается (например, эквивалент $3-5) только за открытие контактов кандидата, с которым произошел Match.  

Enterprise Подписка: Крупные сети (например, Akfa Medline, Vitamed Medical) покупают ежемесячную подписку на премиум-доступ (аналог модели Healthtal), которая позволяет проактивно искать кандидатов по базе и рассылать приглашения без лимитов.  

Стратегия выхода на рынок (Go-to-Market)
Фаза 1 (Набор массы): Запуск Telegram-бота. Парсинг текущих вакансий из открытых каналов (OLX, hh, telegram) для создания первоначальной ценности для врачей. Агрессивный маркетинг среди студентов медвузов.  

Фаза 2 (B2B продажи): Когда в базе наберется первые 1000-2000 верифицированных анкет, старт продаж доступа частным клиникам (предложение первых 5 "мэтчей" бесплатно).

Фаза 3 (Интеграция): Построение API с локальными ATS (например, Jobster) и медицинскими системами, чтобы вакансии из клиник автоматически выгружались в базу ezguMed.
